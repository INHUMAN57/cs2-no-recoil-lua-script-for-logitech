A Logitech G Hub Lua script designed to reduce weapon recoil in **Counter-Strike 2**. The script supports different in-game sensitivities and mouse DPI settings, allowing you to configure it for your setup.

## ✨ Features

* 🎯 Supports custom in-game sensitivity
* 🖱️ Supports custom mouse DPI
* 🔫 Weapon toggle functionality
* ⚙️ Configurable Lua settings
* 🖥️ Designed for Logitech G-series mice
* 🎮 Supports the latest version of Counter-Strike 2 at the time of release

## ⚙️ Configuration

Before using the script, open the Lua file and update the configuration values to match your setup.

### 🎮 In-Game Sensitivity

Find:

```lua
ingamesensitivity = 3.4
```

Replace `3.4` with your **Counter-Strike 2 in-game sensitivity**.

Example:

```lua
ingamesensitivity = 2.5
```

### 🖱️ Mouse DPI

Find:

```lua
dpi = 400
```

Replace `400` with your mouse's current DPI.

Example:

```lua
dpi = 800
```

Make sure the DPI value matches the DPI configured in Logitech G Hub.

## 🎮 Controls

### Recoil Control

Hold the **Left Mouse Button (LMB)** to activate recoil control.

### Weapon Toggle

Use **Mouse Button 5** to toggle the selected weapon/function.

## 📋 Requirements

* Logitech G-series mouse
* Logitech G Hub
* Counter-Strike 2
* Windows

## 🚀 Installation

1. Install **Logitech G Hub**.
2. Connect your compatible Logitech G-series mouse.
3. Create or open your Counter-Strike 2 profile.
4. Add the Lua script to the profile.
5. Configure your in-game sensitivity and DPI in the script.
6. Save the configuration.
7. Launch Counter-Strike 2 and test the script.
